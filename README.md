# hormat-studio — داشبورد پذیرش مرکز رشد (پارک علم و فناوری هرمزگان)

## شروع
1. کل پوشه را روی رایانه نگه دارید و `dashboard.html` را با Chrome یا Edge باز کنید (بدون نصب و بدون اینترنت؛ فقط API و لینک‌های راهنما اینترنت می‌خواهند).
2. تب «راهنمای مبتدی» را بخوانید، بعد «ویزارد».
3. (اختیاری) دکمهٔ «اتصال به پوشهٔ پروژه» را بزنید تا تصاویر و مدارک انتخابی خودکار در مسیر درست کپی شوند.

## ساختار
```
dashboard.html      ویزارد اصلی (۱۷ مرحله + راهنما + خروجی)
bmc.html            بوم مدل کسب‌وکار مستقل (PDF، bmc.json، پرامپت)
Assets/
  css/ js/ fonts/   کد و فونت Estedad (js/schema.js = ساختار فیلدها؛ js/deck.js = پاورپوینت)
  brand/            لوگو
  product/          تصاویر محصول
  team/<نام-لاتین>/ photo, national-card, education, military-service, resume
  docs/             رسید واریز، کاربرگ، bmc.pdf
  exports/          پاورپوینت‌های ساخته‌شده
data/               project.json و نمونه‌های آزمایشی (فرضی)
prompts/            قالب خام پرامپت GSAP / مربی ارائه / داور
```
## نکته‌های مهم
- مدارک هویتی و کد ملی/تلفن/ایمیل/آدرس هرگز در پرامپت‌ها نمی‌آیند. در پاورپوینت فقط عکس عضو و (در اسلاید آخر) ایمیل/تلفن ثبت‌شده می‌آید.
- فونت پاورپوینت باید روی رایانهٔ ارائه نصب باشد (پیش‌فرض Tahoma).
- نمونه‌های `data/sample-*` کاملاً فرضی‌اند.
